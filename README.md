Лабораторна робота 1. Сервіс каталогу вправ з AI-компонентом
Проєкт — це сервіс для роботи з каталогом тренувальних вправ. Він дозволяє отримувати список вправ і додавати нові через HTTP API. Для кожної вправи зберігаються назва, рівень складності та необхідний інвентар. Також є можливість створити вправу на основі звичайного тексту за допомогою заглушки ШІ-моделі.
Структура проєкту:
app/ — код сервера на FastAPI та основна логіка програми.
tests/ — автоматичні тести для перевірки роботи сервісу.
notebooks/01_experiment.ipynb — ноутбук, у якому перевіряються різні варіанти текстових запитів.
notebooks/02_api_verification.ipynb — ноутбук для перевірки роботи API через HTTP-запити.
spec.md — файл зі специфікацією та вимогами до сервісу.
Як запустити проєкт:
Встановлення залежностей Відкрити термінал у папці проєкту та виконати команду: pip install fastapi uvicorn pytest requests jupyter
Перший ноутбук Відкрити notebooks/01_experiment.ipynb і виконати всі клітинки через Restart Kernel -> Run All. У ньому перевіряється, як сервіс працює з різними текстовими запитами.
Запуск тестів Щоб перевірити основну логіку програми, виконати в терміналі: py -m pytest
Запуск сервера В окремому терміналі виконати: py -m uvicorn app.main:app --reload Після запуску API буде доступне за адресою http://127.0.0.1:8000.
Перевірка API через другий ноутбук Не зупиняючи сервер, відкрити notebooks/02_api_verification.ipynb і виконати всі клітинки по черзі. Ноутбук надсилає запити до запущеного сервера та показує результати перевірок у таблиці.
Зберігання даних і перевірка збою моделі:
Дані зберігаються в оперативній пам'яті, тому після перезапуску сервера додані вправи зникають.
Для перевірки роботи сервісу, коли ШІ-модель недоступна, передбачений ендпоінт POST /debug/toggle-outage. Він вмикає або вимикає режим помилки моделі. Це дозволяє перевірити, чи можна додавати вправи вручну, коли обробка тексту через модель не працює.
