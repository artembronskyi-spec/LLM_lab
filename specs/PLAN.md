# План розробки та задачі (Exercise Catalog Service)

## 1. Архітектурні рішення та обмеження
- **Версія Python:** Python 3.11.
- **Фреймворк:** FastAPI (з використанням Uvicorn як HTTP-сервера).
- **Сховище даних:** In-Memory List (збереження даних у оперативній пам'яті).
  - *Обмеження:* Дані зберігаються лише під час роботи процесу сервера й очищуються при кожному перезапуску. Це свідоме рішення для ізольованого та відтворюваного тестування.
- **AI-компонент (`app/services.py`):** Містить логіку валідації та режим `MockLLMService`.
  - *Функціонал Mock:* Дозволяє повністю симулювати всі сценарії (успішна пропозиція, некоректні дані/галюцинації, неповний текст та збій мережі 503) без реальних запитів до зовнішніх API.
